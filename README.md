# Jogo do número secreto

Jogo no navegador em que você tenta adivinhar um número sorteado entre 1 e 50. A cada tentativa, o jogo diz se o número secreto é maior ou menor e, ao final, mostra quantas tentativas foram necessárias. As mensagens também são lidas em voz alta.

**Jogue aqui:** [marinhuuu.github.io/numero-secreto/NUMERO-SECRETO](https://marinhuuu.github.io/numero-secreto/NUMERO-SECRETO/)

## O que pratiquei

- Lógica de programação com condicionais, funções e listas.
- Manipulação do DOM e eventos em JavaScript.
- Sorteio sem repetir números até que todos tenham saído.
- Layout com HTML5 e CSS3.
- Uso de uma biblioteca externa de voz (ResponsiveVoice).

## Como rodar

Abra `NUMERO-SECRETO/index.html` no navegador. A leitura em voz alta e as fontes precisam de internet.

## Tecnologias

JavaScript, HTML5 e CSS3.
